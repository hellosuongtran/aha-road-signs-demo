# AHA Road Signs: replay

Static replay of the automatic road-sign pipeline: street photo → sign read against QCVN 41 → merge sightings → snap to road edge and travel direction → publish gate → map.

Open: https://hellosuongtran.github.io/aha-road-signs-demo/
