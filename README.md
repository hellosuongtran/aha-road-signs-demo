# AHA Road Signs: static console

Static copy of the AHA Road Signs console for GitHub Pages: sign overview, truck navigation on precomputed sample routes, photo review layers, and a replay of the pipeline from a street photo to a sign on the map (`/replay/`).

Open: https://hellosuongtran.github.io/aha-road-signs-demo/
